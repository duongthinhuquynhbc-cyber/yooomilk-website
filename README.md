# YoooMILK website

## Nội dung triển khai
Website được xây dựng dựa trên nội dung tài liệu SEM.docx đến hết Chương 2:
- Định hướng thương hiệu: “Một giọt tươi – Một ngày lành”.
- Danh mục: sữa dê tươi nguyên chất, sữa dê tươi ít đường, sữa dê Organic, sữa hạt hạnh nhân, sữa chua YoooMILK.
- Cấu trúc: Trang chủ, Sản phẩm, Khuyến mãi, Câu chuyện YoooMILK, Liên hệ.
- Thiết kế: trắng, xanh dương nhạt, xanh lá; font sans-serif; responsive.
- Nền tảng dự kiến: GitHub Pages.

## Chạy thử
Mở `index.html` bằng trình duyệt hoặc dùng Live Server trong VS Code.

## Xuất bản GitHub Pages
1. Tải toàn bộ nội dung thư mục này lên repository GitHub.
2. Vào Settings > Pages.
3. Chọn Deploy from a branch, branch `main`, folder `/ (root)`.
4. Save và đợi GitHub Pages triển khai.

## Việc cần thay trước khi dùng chính thức
- Xác nhận URL canonical trong `index.html`, `robots.txt`, `sitemap.xml` nếu dùng URL khác.
- Thay hình minh họa SVG bằng ảnh sản phẩm/bao bì thực tế đã được phép sử dụng.
- Bổ sung giá, thành phần, quy cách, hướng dẫn bảo quản và thông tin liên hệ đã xác minh.
- Cập nhật chính sách giao hàng/đổi trả đúng với chính sách thực tế.
- Biểu mẫu liên hệ và nút tạo đơn hiện là bản demo phía trình duyệt: nội dung được sao chép, chưa gửi lên máy chủ.
- Không có thanh toán, quản trị đơn hàng, tài khoản hay tồn kho phía máy chủ.

## SEO
Đã chuẩn bị title, meta description, canonical, Open Graph, alt text, JSON-LD Organization, robots.txt và sitemap.xml ở mức nền tảng. Sau khi xuất bản, xác minh website trên Google Search Console và gửi sitemap.


## Bản cập nhật giao diện YoooMILK
- Đã thay câu giới thiệu trang chủ theo đúng nội dung người dùng cung cấp.
- Đã chuyển màu nhận diện sang xanh dương sữa và xanh lá, giữ nguyên bố cục và cấu trúc trang.
- Đã thay hình minh họa ở banner, danh mục, thẻ sản phẩm, khuyến mãi và câu chuyện thương hiệu bằng ảnh sản phẩm trên website YoooMILK tham chiếu.
- Ảnh đang được gọi từ website tham chiếu qua URL công khai; nếu website nguồn đổi đường dẫn hoặc gỡ ảnh thì ảnh ở bản này có thể không hiển thị.
